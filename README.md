# Newton Tutorials - Coaching Institute Template

A modern, responsive, and high-conversion landing page template designed specifically for coaching institutes, tuition centers, and educational academies. This project is built using Next.js 14, Tailwind CSS, and Lucide React.

## 🚀 Features

- **Modern & Premium Design**: Beautiful UI with subtle animations, gradients, and a clean aesthetic.
- **High-Conversion Layout**: Strategically placed Call-To-Actions (CTAs), WhatsApp integration, and "Book Demo" flows.
- **Mobile-First Approach**: Fully responsive design with a sticky mobile bottom bar for quick actions (Call & WhatsApp).
- **SEO Optimized**: Built with Next.js for better performance and Search Engine Optimization.
- **Component Sections**:
  - Hero Section with floating elements
  - Statistics/Counters (Students, Reviews, Ratings)
  - Features/Why Choose Us
  - Course/Program Cards (JEE, NEET, Foundation)
  - Testimonials (Marquee scrolling)
  - Results Section
  - FAQ Accordion
  - Location Map & Visit Us Info

## 🛠️ Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Language**: TypeScript

## 📦 Getting Started

```bash

# or
yarn dev
# or
pnpm dev
# or

```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## ⚙️ Configuration & Customization

You can easily customize the content to fit your specific institute by modifying the config section at the top of `app/page.tsx`:

1. **Contact Details**: Update the `phoneNumber` variable for WhatsApp and Calling links.
2. **Programs & Courses**: Edit the `courses` array to match your offerings.
3. **Reviews & Results**: Update `reviewsRow1`, `reviewsRow2`, and `results` arrays with your actual data.
4. **FAQs**: Modify the `faqs` array to answer common questions from your students/parents.
